# Timer Easy Send

Petite fenêtre toujours à l'écran qui affiche la tâche du moment de la to-do Easy Desk (Easy Send), avec le temps
qui reste, et le planning de la semaine en grand. Il faut un compte Easy Send pour s'en servir : chacun ne voit que
ses propres tâches.

- Windows : installateur fabriqué sur le PC (`npm run installateur`).
- Mac : fabriqué ici, sur une machine Mac de GitHub, à chaque mise à jour du code
  (`.github/workflows/mac.yml`). Le fichier se télécharge dans l'onglet « Releases ».
